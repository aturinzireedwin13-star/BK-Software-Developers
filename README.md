# BK Software Developers — Complete Website

A complete responsive premium one-page website for BK Software Developers.

## Included
- Complete hero, services, products/apps, selected work, happy customers, process, about and contact sections.
- The three supplied customer images are included locally in `assets/`.
- GSAP + ScrollTrigger animations are loaded from jsDelivr in `index.html`.
- Responsive navigation and mobile layout.
- Custom cursor, magnetic CTA, scroll reveals, image parallax and hover interactions.
- Favicon included.

## Run
Open `index.html` directly in a modern browser, or deploy the entire folder to GitHub Pages, Netlify, Vercel or another static host.

## Contact form
Replace `YOUR_EMAIL@example.com` in `script.js` with your real business email. The form uses a `mailto:` action and does not require a backend.
